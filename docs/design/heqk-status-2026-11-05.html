3. Decided (design, no code)

  • BOI/HBG = optional, isolated, observe-only behavioural intelligence; the genome is on-device state, never policy (θ signed logic vs S fold over the entity's own observations; empirical Bayes, adaptive thresholds and on-device calibration are training — forbidden).
  • Remote evidence is inert: authority ≠ truth — operator-signed pattern for priors/thresholds/allowlists; node evidence has no code path into local state; three trust levels.
  • Pattern-break ladder: see it → step-up → corroborated containment through the operator-signed reach plane → automatic drop only within ADR 0023's four classes. "Pattern break ⇒ drop" is forbidden, not deferred.
  • Root-cause UI contract: explanation envelope + pattern (established neighbourhood as a small graph), break (the deviating edge with its history), ladder_rung — rendered evidence, never a narrative.
  • Next ADR = 0048: privacy/profiling stance, licensing boundary, real entity identity.

5. Method lessons banked

  • Stop guessing on SDIO/Wi-Fi — measured facts, brcmfmac source, or a Linux trace on the same hardware; one pre-decided image per hypothesis. Every real fix this week came from a trace or a profiler.
  • Exhaust host/QEMU proof, flash once; snapshot images to a private path (a shared build path was overwritten once).
  • Read the serial log in order; faults=0 is not "no loss".
  • An attacker may influence what heqk observes, never what heqk trusts.
