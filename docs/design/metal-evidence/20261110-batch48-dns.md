- **p90:** under 500 ms in every run (207 / 391 / 275 ms; baseline 395 / 207 / 283 ms). The 3.4 s of batch 48 was the measurement.
- **Loss:** heqk 8/120 vs baseline 4/120 pooled. Fisher's exact test gives p ≈ 0.4: not distinguishable. Both replies take the same AP path (UDP source port 53 → TX priority queue), and losses occur on the shared saturated air link.
- **Bar:** a per-run "lost ≤ baseline" on 1–3 losses fails about half the time for identical paths. The proposal for the operator is in the human register (pooled loss over ≥ 3 interleaved runs not significantly worse, or ≤ baseline + 1 per run, AND p90 < 500 ms).
