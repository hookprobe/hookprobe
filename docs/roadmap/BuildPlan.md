## 🏁 MILESTONE M1 — HookProbe OS runs, defends, and self-heals on real hardware (2026-07-20)

**HookProbe OS is real.** A single signed OCI-derived image (`hookprobe-os-pi-debug-v8`, sha256 `ed6a151e…`) boots the **full SOC** on two different Raspberry Pi boards — **Pi 4 (Cortex-A72)** and **CM5 (Cortex-A76)** — and every load-bearing invariant is proven on metal, from the *signed image itself* (not a hot-patch), on both SKUs:

- **Boots clean & healthy** — `systemctl is-system-running` = `running` (not degraded), `HOOKPROBE-SELFTEST: PASS`, all `hookprobe-*`/`napse-*` engines live, evidence graph + QSECBIT scoring producing.
- **One image, both platforms** — same rootfs on A72 + A76; arch-aware AOT (baseline `.cwasm` selected correctly on A72), hybrid **ML-DSA-65 + Ed25519** signed modules verified→running.
- **Wi-Fi AP at hardware max** — autonomous calibration lands + holds **5 GHz VHT80/ch40** unattended (CM5 267 Mbit/s / Pi4 105 Mbit/s — the difference is antenna, not code); regdomain-from-WAN; the 3 AM optimizer + bandit learning.
- **Reflex enforcement is LIVE** — the ADR-0023 `decide()` path delivers verdicts in real time on quiet *and* busy devices; host-EDR + NAPSE L2/L7 detection wired to wire (mirror → napse-dpi).
- **⭐ Enforcement-separation PROVEN on metal (ADR 0023)** — the load-bearing security promise: a **non-mgmt attacker is detected → quarantined** (nft `@quarantine_wan_ips` drop + wire-speed eBPF, **self-reverting** 5-min TTL), while a **legitimate / management connection ALWAYS passes** (mgmt scanner detected but explicitly `log_only`/skipped; 0 enforcement action; SSH never dropped). *Observe by default; drop only a genuine attack; the customer always gets through.* Validated attacker-caught **and** legit-passes, both directions, both boards.
- **DFS closed honestly** — root-caused to a brcmfmac firmware limitation (fix-tested to exhaustion), pivoting Wi-Fi's differentiation to a **security surface** (ADR 0042: WIDS + own-the-radio).

The road here (this session): **DFS root-cause + ADR 0042 pivot → BUG-W7/N1/N2 fixed → a 5-agent autonomous Product-Cortex validation sweep (7 more defects, incl. a privesc a fix had amplified) → the two reflex-engine bugs TA2 (watchdog crash-loop) + TA1 (rate-dependent mawk/stdout buffering starvation, re-diagnosed from a false "A72 bug") → separation matrix proven.** Every fix hot-patch-proven live before the final build (operator's "live-first, build-once" directive). This is **Track B's foundational milestone: the OS boots, detects, enforces with a customer-safe floor, and self-heals — on owned hardware, from a signed image.**
