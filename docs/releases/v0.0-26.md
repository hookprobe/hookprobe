# HookProbe OS v0.0-26 "Zamolxis"

**Version:** `v0.0-26` (SemVer `0.0.26`) · **Codename:** Zamolxis · **Classified:** 2026-11-14 (operator)
**Scheme:** [ADR 0012 D1 amendment](../adr/0012-release-definition-cortex-pass.md) · **Identity in code:**
[`os/kernel/hal/src/release.rs`](../../os/kernel/hal/src/release.rs)

Zamolxis is the first named release of HookProbe OS: the heqk microkernel replacing Linux, with Mission Control
served from the device itself. It classifies the state of `main` on 2026-11-14. It is a **pre-release** (`0.0`):
the CM5 validation gate (H0) is still open.

## What it is

- **heqk on Raspberry Pi CM5 and QEMU.** Zero-Linux factory image, metal-proven on CM5 (full prod-mc acceptance,
  2026-11-04); signed boot with hybrid Ed25519 + SLH-DSA verification and A/B tryboot rollback.
- **Mission Control on the device** (ADR 0047): the UI and API served by heqk, standalone, no account; HTTPS once
  a certificate is provisioned, plain HTTP until then (ADR 0051).
- **Detection and enforcement** under the enforcement-separation rule (ADR 0023): observe by default, drop only a
  genuine attack or resource exhaustion.
- **Secure configuration** (ADR 0058 / 0059): owner-signed configuration, trial / commit / revert.
- **Shield DNS protection** (ADR 0052 / 0057), Wi-Fi STA and AP on the CM5 radio, WAN with PPPoE and IPv6.

Status per feature and its evidence: [Build Plan](../roadmap/BuildPlan.md),
[gap register](../design/heqk-parity-gaps.md).

## How the device reports it

| Where | What you see |
|---|---|
| Boot console | `os  : HookProbe OS v0.0-26 "Zamolxis"` under the HEQK Core banner |
| `GET /api/system` | `"version": "0.0-26", "codename": "Zamolxis"` |
| `hsh` → `version` | `HookProbe OS v0.0-26 "Zamolxis" - HEQK build <id>` |
| Mission Control → Administration → Operating system | `v0.0-26 "Zamolxis" · build <id>` |

## Not in this release

- CM5 validation (H0) is open: REL-05 soak, REL-06..08, SEC-05 sign-off (see the Build Plan).
- Other platforms (RK3588, x86_64, cloud) are not ported yet (ADR 0047 D4).
- The HookProbe board ([`hardware/`](../../hardware/)) is a design in progress, not a product (ADR 0064).

## Release mechanics

The git tag `v0.0-26` and a signed release image are operator steps (Red): build with `os/build/`, sign with the
release key, then tag. This note classifies the source; it does not claim a published image.
